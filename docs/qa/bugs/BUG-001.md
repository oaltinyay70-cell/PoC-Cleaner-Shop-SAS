# BUG-001: Route ordering causes /followup and /top to be unreachable

**Severity**: MEDIUM
**Status**: OPEN
**Found in**: initial implementation
**Platform**: Backend
**Linked TC**: TC-010
**Linked FR**: FR-071, FR-072

## Description
In `src/routes/customers.ts`, the `/:id` route is registered before `/followup` and `/top`. Express matches routes in registration order, so requests to `/api/customers/followup` are caught by `/:id` first, treating "followup" as a UUID parameter.

## Steps to Reproduce
1. Start the API server
2. Send GET /api/customers/followup with valid auth token
3. Observe response

## Expected Result
List of customers due for follow-up (FR-071)

## Actual Result
`{ error: "Customer not found" }` (404) because "followup" is treated as a customer ID

## Fix
Move `/followup` and `/top` route registrations ABOVE `/:id` in customers.ts.
